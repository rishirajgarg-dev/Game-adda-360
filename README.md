# Game Zone Manager

Gaming cafe web app / PWA configured for 8 stations.

## Current features
- 1 PS5, 2 PS4, 4 Xbox 360, 1 Sim Racing
- 5–60 minute sessions in 5-minute intervals
- Manual start time + live countdown
- 1–4 players per station with separate player bills
- Player-wise snacks and billing
- Payment at session end: Cash / Online / Udhar
- Separate Online payment section
- Separate Udhar section with outstanding balances
- Separate Jama section for Udhar recovery
- Daily reports, history, snack stock, CSV exports and backup/restore

Existing UPI/Card history is automatically counted under Online. Pending/Udhar bills continue to create Udhar ledger entries.
